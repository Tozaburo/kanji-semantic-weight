# 加工済みデータについて

このディレクトリには、chiVe Japanese word embeddings から派生した加工済みデータが含まれます。

## 含まれるファイル

- `vectors.bin`: 変換済みベクトルデータ
- `vocab.json`: 語彙とインデックスの対応表

## 元データ

chiVe Japanese word embeddings
